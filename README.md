# 20-10

Landing page / lá thư chúc mừng **Ngày Phụ nữ Việt Nam 20/10**.

## Cách mở

Mở `index.html` bằng trình duyệt (cần mạng để tải font và thư viện tạo ảnh).

## Tính năng

- Chọn thành viên trong gia đình để cá nhân hóa lời chúc
- Random lời chúc dạng lá thư
- Sao chép thư / tải ảnh PNG để gửi
