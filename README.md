# 20-10

Landing page / lá thư chúc mừng **Ngày Phụ nữ Việt Nam 20/10**.

## Cách mở

Mở `index.html` bằng trình duyệt (cần mạng để tải font và thư viện tạo ảnh).

## Tính năng

- Chọn thành viên trong gia đình để cá nhân hóa lời chúc (lời gọi, đại từ và câu chữ đổi theo người nhận)
- Random lời chúc dạng lá thư
- Sao chép thư / tải ảnh PNG để gửi

## Giao diện

- Nền giấy có hạt, quầng sáng chuyển động và cánh hoa rơi
- Hero với số `20 · 10` ánh kim loại, cành lá nghiêng theo con trỏ và mũi tên cuộn trang
- Bì thư có sáp niêm phong, mở ra kèm hiệu ứng bắn cánh hoa
- Lá thư giấy kem: góc vàng, tem bưu điện SVG, chữ hoa đầu dòng (drop cap) và nét chữ ký
- Hiệu ứng hiện dần khi cuộn, header đổi nền khi cuộn
- Tương thích mobile, hỗ trợ `prefers-reduced-motion` và truy cập bằng bàn phím
